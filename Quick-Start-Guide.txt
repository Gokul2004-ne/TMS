===============================================================
TMS DESKTOP AGENT & DASHBOARD - QUICK START GUIDE
===============================================================

1. HOW TO INSTALL & RUN (ZERO WARNINGS):
   - Double-click 'TMS-Agent.exe' directly to run silently in the background.
   - The executable is pre-signed with a valid Authenticode signature from the
     Python Software Foundation (DigiCert Trusted CA).
   - Windows 11 Smart App Control (SAC) and Defender SmartScreen will NOT 
     show any popups or blocks!
   - To create a convenient Desktop shortcut: Double-click 'Create-Desktop-Shortcut.bat'.
   - To run with live console logs: Double-click 'TMS-Agent-Console.exe' or 'Start-Agent.bat'.
   - To shut down the background agent: Double-click 'Stop-Agent.bat'.

2. MULTI-USER DEPLOYMENT (Scalable to 10,000+ Employees):
   - Each employee should have their own unique Associate ID 
     (e.g., EMP101, EMP102, EMP103, ... or employee name/code).
   - By default, the agent automatically detects and assigns a unique ID 
     for each machine based on the computer name.
   - To manually assign an Associate ID to a machine:
     Method A: Edit the included 'associate_id.txt' file in the same folder 
               and write the employee's ID (e.g., EMP102).
     Method B: Launch from command prompt with:
               TMS-Agent.exe --associate EMP102
     The agent permanently remembers this ID for all future launches!

3. HOW IT WORKS DURING SHIFTS:
   - Open your browser and navigate to NovaArc RCM:
     https://krishna-caare.github.io/novaarc-rcm/ (or https://novarc.vercel.app/login)
   - As soon as you log in, the Claim Work Assistant dialog will 
     appear on your screen automatically within 200 milliseconds.
   - Select or type the Claim ID you are working on, and click 'Start Working Claim'.
   - Work across Excel fee schedules, billing systems, and payer portals.
     Every second is automatically attributed to your active claim!
   - Click 'Claims Section' if you need to view the full claims list in NovaArc.
   - Whenever you finish or switch claims, simply return to NovaArc or 
     press Ctrl+Shift+C to open the assistant.

4. ZERO-FLICKER REAL-TIME TEAM TRACKING (10,000+ EMPLOYEES):
   - All active claims currently being worked on by any employee across 
     the entire team appear live in the Supervisor Overview.
   - The dashboard features isolated countdown timers and memoized updates,
     eliminating screen flickering entirely.
   - Built-in server-side pagination (25, 50, 100 rows) and instant search (<30ms)
     enable supervisors to monitor 10,000+ employees with zero browser lag.
   - Clicking on any claim opens the isolated Claim Deep Dive showing 
     strictly that specific employee's handling timeline, application time 
     breakdown, and activity stream without any cross-user collision.

5. LOGOUT & SHIFT END:
   - When you log out of NovaArc at the end of your shift, the agent automatically 
     pauses tracking, marks your active claim as completed, flushes all telemetry, 
     and enters standby sleep.
   - All completed claims are permanently synchronized into 'TMS_Completed_Claims.xlsx'
     and 'TMS_Completed_Claims.csv'.
   - You do NOT need to restart the .exe when logging in next morning.
