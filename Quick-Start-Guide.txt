===============================================================
TMS DESKTOP AGENT - QUICK START GUIDE
===============================================================

1. HOW TO INSTALL & RUN:
   - Extract 'TMS-Agent.zip' to any location on your PC (e.g., Desktop or Documents).
   - Double-click 'Start-Agent.bat' or 'Launch-TMS-Agent.vbs' (recommended for silent launch).
   - Or double-click 'TMS-Agent.exe' directly.
   - The agent runs silently in the background with zero lag and sub-200ms response time.
   - It will automatically register to start up with Windows on reboot.

1b. IF WINDOWS DEFENDER SMARTSCREEN APPEARS ("Windows protected your PC"):
   - Because this internal tool is built directly for your company, Windows SmartScreen
     may display a blue "Windows protected your PC" alert on first launch.
   - Method A (Instant Click - 2 Seconds):
     1. Click "More info" (underlined link on the popup).
     2. Click the "Run anyway" button that appears at the bottom right.
   - Method B (Double-Click Launcher):
     1. Simply double-click 'Start-Agent.bat' or 'Launch-TMS-Agent.vbs'.
     2. The launcher automatically unblocks all files and runs the agent cleanly!
   - Method C (Unblock File Properties):
     1. Right-click 'TMS-Agent.exe' -> Select 'Properties'.
     2. In the 'General' tab at the bottom, check the 'Unblock' box.
     3. Click 'Apply' then 'OK'. SmartScreen will never show again!

1c. IF WINDOWS 11 "SMART APP CONTROL" BLOCKS THE APP ("Smart App Control blocked an app"):
   - Smart App Control (SAC) is a Windows 11 feature that blocks unsigned .exe files 
     if they carry the internet download tag ("Mark of the Web").
   - Solution 1 (Automatic Launcher - Recommended):
     Double-click 'Start-Agent.bat' or 'Launch-TMS-Agent.vbs'. 
     The launcher strips the download tag and starts the agent smoothly!
   - Solution 2 (Unblock the ZIP before extracting):
     1. Right-click the downloaded 'TMS-Agent.zip' -> Select 'Properties'.
     2. At the bottom of the General tab, check 'Unblock' and click 'OK'.
     3. Extract the ZIP. All extracted files will now run freely without any SAC block!
   - Solution 3 (Run via Python):
     If Python is installed on your workstation, double-clicking 'Start-Agent.bat'
     will automatically launch via the trusted Microsoft-signed Python interpreter.

2. MULTI-USER DEPLOYMENT (30+ Employees):
   - Each employee should have their own unique Associate ID 
     (e.g., EMP101, EMP102, EMP103, ... or employee name/code).
   - By default, the agent automatically detects and assigns a unique ID 
     for each machine based on the computer name.
   - To manually assign an Associate ID to a machine:
     Method A: Edit the included 'associate_id.txt' file in the same folder 
               and write the employee's ID (e.g., EMP102).
     Method B: Launch from command prompt with:
               TMS-Agent.exe --associate EMP102
     The agent permanently remembers this ID for all future launches!

3. HOW IT WORKS DURING SHIFTS:
   - Open your browser and navigate to NovaArc RCM:
     https://krishna-caare.github.io/novaarc-rcm/
   - As soon as you log in, the Claim Work Assistant dialog will 
     appear on your screen automatically within 200 milliseconds.
   - Select or type the Claim ID you are working on, and click 'Start Working Claim'.
   - While the dialog is open, application and website switching are locked 
     to ensure focused claim assignment.
   - Click 'Claims Section' if you need to view the full claims list in NovaArc.
   - Whenever you finish or switch claims, simply return to NovaArc or 
     press Ctrl+Shift+C to open the assistant.

4. REAL-TIME TEAM TRACKING:
   - All active claims currently being worked on by any employee across 
     the entire team appear live in the Team Lead's "Today's Claim Activity Log" 
     with a real-time ticking duration and status indicator.
   - Clicking on any claim opens the isolated Claim Deep Dive showing 
     strictly that specific employee's handling timeline, application time 
     breakdown, and activity stream without any cross-user collision.

5. LOGOUT & SHIFT END:
   - When you log out of NovaArc at the end of your shift, the agent automatically 
     pauses tracking, marks your active claim as completed, flushes all telemetry, 
     and enters standby sleep.
   - You do NOT need to restart the .exe when logging in next morning.
